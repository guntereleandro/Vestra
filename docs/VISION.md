# Visão do Vestra

O Vestra existe para ajudar pessoas a compreenderem seu patrimônio com clareza.

Não somos apenas um sistema de investimentos.

Somos um painel de controle do patrimônio.

Toda tela deve responder:

"Como está meu patrimônio hoje?"

Toda funcionalidade deve tornar essa resposta mais clara.

Toda decisão de design deve transmitir:

- confiança;
- simplicidade;
- velocidade;
- elegância.

O usuário deve sentir que está utilizando uma plataforma premium.
