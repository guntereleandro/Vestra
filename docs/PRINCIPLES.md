# Princípios do Vestra

1. O patrimônio é o protagonista.

2. O usuário deve entender sua situação financeira em menos de 5 segundos.

3. Nunca esconder informações importantes atrás de muitos cliques.

4. Toda funcionalidade deve responder a um problema real.

5. Clareza é mais importante que quantidade de informações.

6. O Vestra informa; o usuário decide.

7. A confiança do usuário vale mais do que qualquer efeito visual.
